# Projects

## University

### Metaheuristics
- [MAXSAT Solver](https://github.com/Goncalo-Dias-Rodrigues/MaxSat-BruteForce) - An algorithm that solves the MAXSAT problem with brute-force, searching all possibilities for the optimal one.

### Modern Cryptography
- [Classic Ciphers](https://github.com/Goncalo-Dias-Rodrigues/Classic-Ciphers) - Repository made for studying the cryptography of classic ciphers.

### Machine Learning
- [Linear Regression](https://github.com/Goncalo-Dias-Rodrigues/ML-Linear-Regression) - A linear regression implementation using Jupyter Notebook for studying Machine Learning.

### AI
- [Array Even/Odd Sorting](https://github.com/Goncalo-Dias-Rodrigues/AI_Array_Sorting) - Program that computes the minimum-cost sequence of swaps that converts an initial integer array into a target array, where each elementary swap has a cost depending on the parity of the swapped values.
- [8 Puzzle Solver](https://github.com/Goncalo-Dias-Rodrigues/8-Puzzle_Solver) - Java implementation that solves small instances of the 8-puzzle using a best-first search implemented via the Strategy design pattern.

## Online Courses
